# AI Operating Directives: Anti-Slop Protocol

Every AI agent working in this repository MUST adhere to the **Anti AI Slop Protocol**:

1. **Design & Aesthetics**:
   - Deliver high-taste, modern, minimalist, and intentional UI (Linear / Apple / Vercel grade).
   - Reject generic AI gradient clichés (purple-magenta blasts, random sparkles). Stick to the established brand palette (`#090D16`, `#0066FF`, `#38BDF8`).
   - Every layout, animation, and interaction must feel crafted by a senior human designer.

2. **Code Cleanliness**:
   - Strictly avoid redundant comments, bloated boilerplate, and dead code.
   - Use strict Flutter & Dart standards: `const` constructors, `final` variables, typed callbacks, and zero analyzer warnings.
   - Never use deprecated methods (`withOpacity` -> use `withValues`).

3. **No Fluff**:
   - Write clear, concise, authentic text without corporate AI buzzwords or filler.
